# SI-retail

A design concept for the [Si Retail](https://si-retail.com) homepage — *Quiet Luxury, Everyday*.

Single self-contained `index.html` (no build step). Open it in a browser, or host the folder on any static host (Netlify, Vercel, GitHub Pages).

## Features

- **Cinematic hero** — campaign slideshow with progress indicators
- **Style Studio** — mix and match tops and bottoms, see the look's total, add both to the bag in one tap
- **Fabric Library** — browse pieces by Linen, Cotton & Jersey, Knits, Denim, and Silk, Lace & Sequins, each with its exact material
- **Fabric Passport** — quick view with material, fit, stretch, hand feel, transparency and lining from each product sheet
- **Beyond** — dark showcase for the Signature Collection
- Bag, favourites and search (by name or fabric); checkout hands off to the real si-retail.com cart
- Responsive, keyboard accessible, respects reduced-motion

## Data

Products, prices, colours, sizes, images and copy come from si-retail.com's public product feeds and pages, captured on 20 November 2026. Images load from Si's CDN. Prices and stock may have changed since.

This is a concept preview, not the official store: the page is marked "Design concept", is set to `noindex`, and the newsletter form sends nothing.
